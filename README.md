# CampusConnect - Lecture Hall Management System

A modern web-based **Lecture Hall Management System** that simplifies classroom booking, scheduling, and management for universities. The system allows faculty to reserve lecture halls, administrators to manage resources, and students to view schedules in real time.

---

## 📖 Overview

CampusConnect is designed to eliminate manual classroom allocation and scheduling conflicts by providing a centralized platform for lecture hall management.

The system helps institutions:
- Manage lecture halls efficiently
- Avoid booking conflicts
- Track hall availability
- Simplify timetable management
- Improve communication between faculty and administration

---

## ✨ Features

### 👨‍🏫 Faculty
- Book available lecture halls
- View booking history
- Cancel or modify reservations
- Check real-time hall availability

### 👨‍💼 Administrator
- Add/Edit/Delete lecture halls
- Approve or reject booking requests
- Manage users
- Monitor all reservations
- Prevent scheduling conflicts

### 🎓 Students
- View lecture schedules
- Check classroom allocations
- Search lectures by course or hall

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/your-username/campusConnect.git
```

Move into the project directory

```bash
cd campusConnect
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open your browser

```
http://localhost:5173
```
